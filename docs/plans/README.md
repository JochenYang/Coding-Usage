# 当前计划（plans）

存放**进行中**方案的优先级与验收标准，一篇计划一个文件：`docs/plans/<slug>.md`。

- 计划开头写 `- Status: active | blocked | completed` 与 `- Plan date: YYYY-MM-DD`。
- 正文写目标、范围（做/不做）、验收标准与风险；**不要**写逐任务流水、审查过程或临时脚本清单，
  那些属于 `.devflow/` 工作记录。
- 完成后把状态改为 `completed`，移入 `docs/archive/`，并在 [docs/README.md](../README.md) 无需改动
  （archive 统一登记）。
